## 8. How to Run the Website

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are present.
4. Open index.html in a web browser.
5. Explore the About, Skills and Projects sections.
6. Test the dark/light mode button.
7. Check the Jaipur weather card.

## 9. JavaScript Functionality

The JavaScript file (abcd.js) is included to handle
interactive website features such as:

- Dark and Light mode switching.
- Weather information display.

Note: Weather information requires a working weather
API or weather service integration.
